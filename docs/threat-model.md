# نموذج التهديدات — سوقنا (سوق سوريا)

| المهدد | التهديد | التخفيف |
|---|---|---|
| مستخدم يستغل كونه بائعًا | تعديل/حذف إعلان غيره (IDOR) | Laravel Policy لكل مورد؛ اختبار `Feature` لكل مجموعة صلاحية؛ لا تمرير `user_id` من الطلب |
| مهاجم تسجيل الدخول | تخمين كلمة المرور / Credential stuffing | Argon2id، rate limit حسب IP+بريد (5/دقيقة)، قفل مؤقت، رسالة خطأ موحدة، بريد «نشاط دخول جديد» |
| مزعج (Spammer) | إعلانات/رسائل بالجملة | Rate limit لكل مستخدم (نشر 10/يوم، رسالة 30/ساعة)، فحص رابط/هاتف مكرر، علم تلقائي → `moderation_state` |
| سارق صور | رفع صور خبيثة/كبيرة | فحص magic bytes + إعادة ترميز (libvips)، حد 8MB/25MP، إزالة EXIF/GPS، رفض SVG |
| مهاجم API | إغراق نقاط النهاية (DoS) | Throttle Redis لكل IP وتوكن، حدود أحجام الطلبات، Cursor pagination بحد 50، WAF/CDN أمام ALB |
| مسّرب بيانات | توكنات مسرّبة | Hash للتوكنات (Sanctum)، انتهاء 90 يومًا خمول، تسجيل خروج كلي، كشف إعادة استخدام بسيط |
| محتال | رسائل بروابط/حسابات بنكية | علامات تلقائية على أنماط الاحتيال المعروفة، تحذير في واجهة المحادثة (قاعدة الواجهة) |
| مستخدم ضار | بلاغات انتقامية | تجميع بلاغات الهدف الواحد، وزن سجل المبلّغ، حظر إساءة البلاغ |
| داخلي (مشرف) | إساءة صلاحيات | حسابات إدارية منفصلة، 2FA إلزامي، أقل صلاحية (moderator ≠ admin)، كل فعل في `audit_logs` مع `statement_of_reasons` |
| فقدان بيانات | فساد قاعدة البيانات | PITR مُدار + نسخة يومية مشفرة خارج المزود + اختبار استعادة موثق قبل الإطلاق |
| خطأ تطبيقي | تكرار إعلانات/رسائل عند إعادة المحاولة | `Idempotency-Key` + unique constraints + `client_message_id` |
| ضعف شبكة السوق | طلبات معلقة/بطيئة | استجابات صغيرة، trgm+FTS بدل LIKE المطلق، CDN للصور، مهلة صارمة و`Retry-After` |

**مبادئ حاكمة:** كل مدخل غير موثوق؛ كل إجراء كتابة عبر Policy + Idempotency؛ سجل تدقيق لكل فعل إداري؛ لا رسائل في السجلات (نصّها ممنوع من logs).
