# قائمة الالتزام القانوني والثقة — سوقنا (سوريا)

## سياق القانون
السوق المستهدف **سوريا**؛ لا تنطبق DSGVO وDSA وTDDDG الأوروبية. قبل الإطلاق العام: مراجعة قانونية محلية قصيرة (شروط الاستخدام وسياسة الخصوصية بالعربية، ومسؤولية المنصة عن المحتوى المخالف، وشروط التجار الإلكترونية إن وُجدت تشريعات سورية مطبقة).

## البنود المعتمدة كميزات ثقة (ليست التزامًا قانونيًا أوروبيًا، لكنها جودة)
- **بلاغات مفتوحة للجميع** (ضيوف ببيانات اتصال) مع حالة البلاغ و`statement_of_reasons` عند اتخاذ قرار.
- **تصدير البيانات**: `/me/exports` — كل بيانات المستخدم في ملف قابل للقراءة.
- **حذف الحساب**: فترة سماح 30 يومًا (`pending_deletion`) ثم حذف فعلي.
- **سجل موافقات** `user_consents` إلحاقي للشروط وسياسة الخصوصية والتسويق.
- **شفافية الإشراف**: الإدارة توثق سبب كل فعل (حجب، تعليق، توثيق، رفض).
- **توثيق التجار** كميزة ثقة: شارة «تاجر موثّق» وبيانات اتصال علنية اختيارية.

## الاحتفاظ (Retention)
| البيانات | المدة |
|---|---|
| الرسائل ومحتوى المحادثات | 12 شهرًا |
| الإعلانات المحذوفة | 6 أشهر |
| بلاغات وسجلات الإشراف | 12 شهرًا بعد الإغلاق |
| بيانات `business_profiles` | طوال العلاقة + سنة |
| توكنات الجلسات | 90 يومًا خمول ثم إبطال |
| نسخ احتياطية مشفرة | 35 يومًا |

## لا نجمع ولا نخزن
- كلمات مرور نصية؛ توكنات نصية؛ محتوى الرسائل في السجلات؛ عناوين IP كاملة (نخزن hash).
- إحداثيات GPS دقيقة إن قرر المستخدم عرض موقع عام فقط (نقرّب ~1 كم).

## لاحقًا (عند التوسع لأسواق أخرى)
- إذا فُتح السوق الأوروبي مستقبلًا: DSGVO + DSA + Impressum تصبح متطلبات إطلاق حينها — تصميمنا الحالي لا يمنعها (بلاغات، تصدير، موافقات، سجل أسباب جاهزة).
